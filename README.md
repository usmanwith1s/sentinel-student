# Sentinel Student

A beginner-friendly Java code review and learning assistant for university
students. Runs entirely in the browser — no backend, no accounts, no uploads.

## Status

🚧 Early prototype — see the milestone roadmap in `docs/ROADMAP.md` (coming soon).

## Run locally

Open `index.html` in any modern browser, or use VS Code's
**Live Server** extension for auto-reload during development.

## Privacy

All analysis happens locally in your browser. Source code is never
transmitted or persisted.
